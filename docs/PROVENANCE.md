   “The Clavecin That Never Was” (Seals & Windsor).  
   Historical neural-encoding claim for Hermann Poll / the 14th-century clavecin is **explicitly rejected**.  
   No trained weights were recovered from the original archive; all checkpoints are newly trained after the silent-loss-bug repair.

2. **VME Config A** – symbolic pitch resolver with Prediction Suffix Tree.  
   “Oracle” references inside VME refer only to classical Factor Oracle / Variable Markov Oracle structures; they are unrelated to MagneticOracle.

**Newly designed in the hybrid**
